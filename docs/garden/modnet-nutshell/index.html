MODNet in a nutshell

An interactive explainer for MODNet — the Materials Optimal Descriptor Network. This preview contains the opening argument: materials ML is a small-data game, and that changes which models win.

The small-data problem

Most materials datasets have hundreds to thousands of samples, not millions. The models that win at 60 000 samples are not the models that win at 500. Pick a property and compare mean absolute error as the training set grows.

Data: measured points are verbatim from De Breuck, Hautier, Rignanese, npj Comput. Mater. 7, 83 (2021), Table I. The lines between and beyond those points are a log-log interpolation for the slider, not measured results.

What comes next

The full piece walks the pipeline in execution order: featurization → normalized mutual information → relevance–redundancy selection → the network → joint learning → the genetic algorithm and validation. Each stage gets a widget and a collapsible “in the codebase” panel pointing at the pinned MODNet source.
